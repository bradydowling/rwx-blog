# Celebration emoji artwork

The PNG files in this directory are Twemoji graphics by Twitter and Twemoji contributors, from https://github.com/twitter/twemoji/tree/master/assets/72x72.

They are licensed under Creative Commons Attribution 4.0 International: https://creativecommons.org/licenses/by/4.0/. The upstream graphics license is https://github.com/twitter/twemoji/blob/master/LICENSE-GRAPHICS.

Included icons: 1f4aa (flexed biceps), 270c (victory hand), 261d (index pointing up), 1f44d (thumbs up), 1f590 (hand with fingers splayed), 1f448 (backhand pointing left), 1f449 (backhand pointing right), and 1f918 (sign of the horns). The PNG files are unchanged; the game scales and positions them at runtime.
